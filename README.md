# Library Quest

Library Quest is a voice-based book discovery assistant that guides readers through a quest to find their next read while respecting mood, genre, content preferences, and avoidances.

Rather than functioning as a simple search tool, Library Quest uses a conversational flow to help users narrow down what kind of reading experience they want. The assistant asks about genre, tone, emotional intensity, book length, and themes the user wants to avoid before offering a recommendation.

## Project Purpose

The goal of Library Quest is to explore how voice user interfaces can support book discovery in a more personal and accessible way. Many readers know the feeling they want from a book but may not know the title, genre, or keywords to search for. Library Quest helps turn vague preferences like “something dark but not depressing” or “something cozy and romantic” into a clearer recommendation path.

## Target Users

Library Quest is designed for readers who:

* Want help choosing their next book
* Feel overwhelmed by too many recommendations
* Prefer conversational guidance over scrolling through lists
* Have content preferences or themes they want to avoid
* Want recommendations based on mood, tone, genre, or reading energy

## Key Features

* Mood-based book discovery
* Genre and tone filtering
* Content avoidance preferences
* Reading length preferences
* Conversational follow-up prompts
* Recommendation refinement
* Voice-first interaction design

## Example Interaction

User: I want a fantasy book.

Library Quest: Great. What kind of fantasy quest are you looking for today: cozy, adventurous, dark, romantic, or mysterious?

User: Dark, but not too depressing.

Library Quest: Got it. Are there any themes you want to avoid, such as graphic violence, major character death, horror, or heavy grief?

User: Avoid major character death.

Library Quest: Understood. Do you want a short, medium, or long read?

User: Medium.

Library Quest: I found a dark fantasy option with strong atmosphere and no major character death. Would you like the recommendation, or do you want to narrow it further?
